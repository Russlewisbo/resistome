## 🦠 KPC-31 Resistome Analysis — Project Overview

### What This Is
A bioinformatics/genomic epidemiology project analyzing **42 clinical bacterial isolates** (33 *K. pneumoniae* + 9 *E. coli*) all carrying the **blaKPC-31 carbapenemase gene**. The analysis combines whole-genome sequencing data (resistance genes, plasmids, sequence types) with phenotypic data (MIC values for ~26 antibiotics) to understand genotype-phenotype relationships.

---

### Project Infrastructure
- **Data source:** `Progetto 1 (KPC-31) versione 2.xlsx`
- **Analysis framework:** Quarto website with R (tidyverse, ggplot2)
- **Deployment:** GitHub Pages (auto-deploys from `/docs` folder)
- **Main analysis files:**
  - `resistome_analysis_report.qmd` — comprehensive resistance phenotype & genotype analysis
  - `resistome_genotype_phenotype_final.qmd` — advanced genotype-phenotype correlations
  - `about.qmd`, `index.qmd` — documentation & homepage

---

### Key Scientific Findings So Far
| Finding | Detail |
|---|---|
| **Universal KPC-31** | 100% of isolates carry blaKPC-31 |
| **ST307 Paradox** | Most genes (CTX-M-15, SHV-28) but **lowest** median MIC (~18 mg/L) |
| **ST101** | Few extra genes but **highest** MIC (256 mg/L) |
| **ST512** | 100% CAZ-AVI resistant (IncX3 plasmid) |
| **Non-linear effects** | More genes ≠ higher resistance |
| **CAZ-AVI resistance** | 35.7% of isolates show high-level resistance |
